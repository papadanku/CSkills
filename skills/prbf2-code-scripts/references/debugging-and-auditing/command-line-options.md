
# BF2 / PR:BF2 Command Line Options

Case-sensitive command-line options for `BF2.exe` / `BF2_r.exe` shortcuts (note: some options only work in the `BF2_r.exe` debug build):

- **`+multi`**: Lets you run multiple Battlefield 2 games at the same time. (Usage: `+multi`)
- **`+joinServer`**: Connects to a specific server. You can use either the server's IP address or its hostname. (Usage: `+joinServer` `OR`)
- **`+playerName`**: Sets your player name. (Usage: `+playerName`)
- **`+password`**: Use this with `+joinServer` if the server needs a password. It might also set the password for a dedicated server. (Usage: `+password`)
- **`+lowPriority`**: Makes Battlefield 2 run with lower CPU priority, which means less CPU usage but also lower performance. (Usage: `+lowPriority`)
- **`+loadLevel`**: Loads a specific level. (Usage: `+loadLevel`)
- **`+wx`**: When Battlefield 2 is in windowed mode, this sets the window's horizontal position. 0 is the far left of the screen, and the window is positioned from its left edge. (Usage: `+wx`)
- **`+wy`**: When Battlefield 2 is in windowed mode, this sets the window's vertical position. 0 is the very top of the screen, and the window is positioned from its top edge. (Usage: `+wy`)
- **`+szx`**: When Battlefield 2 is in windowed mode, this sets the window's width. (Usage: `+szx`)
- **`+szy`**: When Battlefield 2 is in windowed mode, this sets the window's height. (Usage: `+szy`)
- **`+loadObfuscated`**: Loads scrambled shaders. The exact purpose is unclear. (Usage: `+loadObfuscated`)
- **`+fullscreen`**: Switches Battlefield 2 between windowed and full-screen modes. (Usage: `+fullscreen`)
- **`+noSound`**: Starts Battlefield 2 without any sound. (Usage: `+noSound`)
- **`+lateLoading`**: If set to 1, game resources (currently only sound) will load only when they are first used. (Usage: `+lateLoading`)
- **`+skipMips`**: Determines how many mip-levels to skip in textures. (Usage: `+skipMips`)
- **`+mergeMaterials`**: Combines materials when the game loads. (Usage: `+mergeMaterials`)
- **`+managedTextures`**: Controls whether system memory is used for textures. (Usage: `+managedTextures`)
- **`+debugOutput`**: Turns debug messages on or off. (Usage: `+debugOutput`)
- **`+demo`**: Sets the configuration file for demo options. Its exact function is unclear. (Usage: `+demo <??>`)
- **`+pyVerbose`**: Shows detailed output from Python scripts. Not very interesting. (Usage: `+pyVerbose`)
- **`+modPath`**: Sets the path where Battlefield 2 looks for mods. Usually, this is :file:`mods/bf2`. (Usage: `+modPath`)
- **`+ignoreAsserts`**: Ignores debug assertion errors. Only works if `+developer 1` or `+dedicated 1` is also used. (Usage: `+ignoreAsserts`)
- **`+disableShaderCache`**: Turns off the shader cache. This should only be used with `+developer 1`. (Usage: `+disableShaderCache`)
- **`+dumpAllConFiles`**: Writes the names of all :file:`.con` files to :file:`mods/$MOD$/allConFiles.con`. (Usage: `+dumpAllConFiles`)
- **`+customConFile`**: Uses a specific :file:`.con` file instead of loading all of them. This file should use the `run` command to specify which other :file:`.con` files to execute. (Usage: `+customConFile`)
- **`+help`**: Shows help information for command line options, including descriptions. (Usage: `+help`)
- **`+?`**: Does the same thing as `+help`. (Usage: `+?`)
- **`+fileMonitor`**: Automatically updates files (like shaders) when they change. This could be very useful if it also applies to :file:`.con` files. (Usage: `+fileMonitor`)
- **`+playerPassword`**: Sets the player's password. (Usage: `+playerPassword`)
- **`+developer`**: Prevents automatic login and allows other command line options to be used with it. (Usage: `+developer`)
- **`+disableSwiff`**: Turns off the Swiff player, which disables the Flash animations used in the main menu. Swiff refers to the :file:`.swf` Flash file format. (Usage: `+disableSwiff`)
- **`+debugSwiff`**: Turns on debug output for Swiff. Swiff refers to the :file:`.swf` Flash file format. (Usage: `+debugSwiff`)
- **`+playNow`**: Starts the game and automatically uses the 'Play Now' feature. (Usage: `+playNow`)
- **`+pbPath`**: Sets the path to Punkbuster for setups with multiple game instances. This is usually :file:`{install_dir}/pb`. (Usage: `+pbPath`)
- **`+keepCollisionForNavMeshes`**: Keeps collision mesh Level of Details (LODs) needed to create AI navigation meshes. The exact function is unclear. (Usage: `+keepCollisionForNavMeshes`)
- **`+restart`**: Used by BF2 to restart the game without showing videos, for example, when switching mods. Can also be used to start BF2 without videos using your own shortcuts. (Usage: `+restart`)
- **`+port`**: Used with `+joinServer` to specify the port number for connecting to a server. (Usage: `+port`)
- **`+dedicated`**: Starts Battlefield 2 as a dedicated server. This is not needed on Linux. (Usage: `+dedicated`)
- **`+port`**: Sets the port number the server should use. (Usage: `+port`)
- **`+maxPlayers`**: Sets the maximum number of players allowed on the server. (Usage: `+maxPlayers`)
- **`+gameMode`**: Sets the game mode for the server. (Usage: `+gameMode`)
- **`+config`**: Sets the path to the :file:`ServerSettings.con` file to use. (Usage: `+config`)
- **`+mapList`**: Sets the path to the :file:`mapList.con` file to use. (Usage: `+mapList`)
- **`+noStatusMonitor`**: Use this if you don't want to run BF2 inside a screen session. (Usage: `+noStatusMonitor` with values 1 (or 0 the default if you don't specify this option at all))
- **`+ranked`**: Allows sending game data to Gamespy. This setting only works if EA has the server's IP address in their database. (Usage: `+ranked`)
- **`+hostServer`**: Currently unknown. Likely starts a local server. (Usage: `+hostServer <??>`)
- **`+checkForAvailablePatch`**: Currently unknown. Likely checks for available patches. When used with the debug version, it causes an error on startup and appears to be broken. (Usage: `+checkForAvailablePatch <??>`)
- **`+checkForPatch`**: Currently unknown. How this differs from `+checkForAvailablePatch` is unclear. When used with the debug version, it causes an error on startup and appears to be broken. (Usage: `+checkForPatch <??>`)
- **`+aidll`**: Currently unknown. Perhaps it enables or disables the Battlefield 2 :file:`aidll.dll` file. (Usage: `+aidll <??>`)
- **`+ai`**: Forces Battlefield 2 to load AI bots, regardless of the map, requirements, or settings. --MasterX (Usage: `+ai <0/1>`)
- **`+refresh`**: Currently unknown. (Usage: `+refresh <??>`)
- **`+renderMode`**: Sets the current rendering mode. Possible values are 0-5, but their specific functions are not yet known. (Usage: `+renderMode`)
- **`+rp`**: Currently unknown. (Usage: `+rp <??>`)
- **`+deviceType`**: Currently unknown. (Usage: `+deviceType <??>`)
- **`+deviceBehavior`**: Currently unknown. (Usage: `+deviceBehavior <??>`)
- **`+skipMeshLods`**: Currently unknown. `LOD <http://en.wikipedia.org/wiki/Level_of_Detail>`_ (Usage: `+skipMeshLods <??>`)
- **`+keepTemplates`**: Currently unknown. (Usage: `+keepTemplates <??>`)
- **`+profileTextureUsage`**: Currently unknown. (Usage: `+profileTextureUsage <??>`)
- **`+convertCollisionMeshes`**: Currently unknown. (Usage: `+convertCollisionMeshes <??>`)
- **`+generateLightMaps`**: Currently unknown. (Usage: `+generateLightMaps <??>`)
- **`+debugNetwork`**: Currently unknown. (Usage: `+debugNetwork <??>`)
- **`+debugGhostManager`**: Currently unknown. (Usage: `+debugGhostManager <??>`)
- **`+compile`**: Currently unknown. (Usage: `+compile <??>`)
- **`+useCompiled`**: Currently unknown. (Usage: `+useCompiled <??>`)
- **`+NoEffectTextureAtlas`**: Currently unknown. (Usage: `+NoEffectTextureAtlas <??>`)
- **`+menu`**: Currently unknown. This is used by Battlefield 2's default shortcut as `+menu 1`. (Usage: `+menu`)
